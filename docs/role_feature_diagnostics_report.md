展示可靠的角色方向、位置与阴影控制。尚不能区分短训练、融合位置、条件方向
未被学会等剩余解释，也不能把冻结权重上的OOD变换当作重新训练方案的否定。

T/D/P作为反事实数据、必要变化/保留区域的评估与失败分析值得保留；作为性能方法

条件方向/注入位置的读出或梯度归因诊断；先设计、无扩量训练，Test继续封存。
